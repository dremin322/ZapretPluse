# Third-party software

Zapret+ is an independent graphical application that integrates third-party software.

## Flowseal / zapret-discord-youtube
Project: https://github.com/Flowseal/zapret-discord-youtube

Zapret+ includes Windows Zapret runtime files, strategies and lists originating from this project.
The upstream project is based on Zapret and contains its own licensing and attribution information.
