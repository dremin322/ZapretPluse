# Zapret+

Zapret+ — графическое приложение для управления Zapret и TG WS Proxy в Windows.

Приложение объединяет оба инструмента в одном интерфейсе и добавляет автоматический подбор стратегии, автовосстановление, диагностику, статистику и обновления.

Zapret+ не является VPN и не заменяет Zapret или TG WS Proxy — приложение управляет этими компонентами через единый интерфейс.

> Windows 10/11 · x64

---

## Установка

1. Нажмите **Code → Download ZIP** и распакуйте проект.
2. Запустите `build_portable.bat`.
3. Дождитесь окончания сборки.
4. Запустите появившийся в корне `ZapretPlus.exe`.

Готово.

`build_portable.bat` сам проверит необходимые компоненты. Если Python отсутствует, он будет установлен автоматически вместе с необходимыми зависимостями.

При запуске Zapret+ Windows запросит права администратора — они необходимы для работы Zapret.

После сборки рядом с `ZapretPlus.exe` появится папка `ZapretPlus\`. Не удаляйте и не перемещайте её отдельно.

Для рабочего стола создавайте **ярлык** корневого `ZapretPlus.exe`.

## Возможности

### Управление из одного окна

Zapret и TG WS Proxy можно запускать и контролировать из одного приложения.

Основные компоненты запускаются кнопкой **«Включить всё»**, но при необходимости ими можно управлять отдельно.

### Стратегии Zapret

Доступные стратегии Zapret отображаются прямо в приложении.

Стратегию можно выбрать вручную или использовать **автоподбор**, чтобы Zapret+ самостоятельно проверил доступные варианты.

### TG WS Proxy

Telegram Proxy запускается и контролируется непосредственно из Zapret+.

Приложение показывает его состояние, активные соединения, трафик и ошибки.

### Автовосстановление

Zapret+ следит за состоянием компонентов и может автоматически восстановить их работу после неожиданной остановки.

### Статистика и диагностика

В приложении отображаются:

- входящий и исходящий трафик;
- активные соединения;
- ошибки;
- время работы.

Отдельный раздел диагностики помогает найти причину проблемы, если один из компонентов не запускается.

### Свои сайты

Дополнительные сайты можно добавлять прямо через интерфейс.

Пользовательские списки хранятся отдельно и сохраняются при обновлении компонентов.

### Обновления

Zapret+ проверяет обновления:

- Zapret+;
- Zapret и его стратегий;
- TG WS Proxy.

Обновления Zapret и TG WS Proxy проверяются по официальным репозиториям Flowseal.

TG WS Proxy обновляется только вместе с совместимой версией Zapret+, чтобы обновление компонента не нарушило работу интеграции.

### Интерфейс

Доступны светлая и тёмная темы, а также настройка основного цвета интерфейса.

## Для разработчиков

Интерфейс Zapret+ написан на **Python + PySide6 (Qt)**.

Основные части проекта:

- `ui/` — интерфейс;
- `core/` — конфигурация и основная логика;
- `engines/` — управление Zapret и TG WS Proxy;
- `services/` — обновления и дополнительные функции;
- `runtime/` — необходимые компоненты Zapret и TG WS Proxy;
- `assets/` — ресурсы интерфейса.

Сборка выполняется через **PyInstaller** с помощью `build_portable.bat`.

После сборки:

- `ZapretPlus.exe` — файл для обычного запуска;
- `ZapretPlus\` — файлы основного приложения и его компонентов.

## Нашли ошибку?

Проверьте раздел **«Диагностика»** в Zapret+.

Если проблема остаётся, создайте **Issue** и укажите:

- версию Windows;
- версию Zapret+;
- описание проблемы;
- результат диагностики.

Перед публикацией логов проверьте, что в них нет данных, которыми вы не хотите делиться.
