# Zapret+ icon guide

For the application icon, keep one lossless 1024×1024 PNG master.

Windows `.ico` should contain these square sizes:
- 16×16
- 20×20
- 24×24
- 32×32
- 40×40
- 48×48
- 64×64
- 128×128
- 256×256

The most important Windows sizes are 16, 32, 48 and 256 px.

Design rules:
- keep the symbol inside a ~10–15% safe margin;
- avoid thin lines below ~2 px at 32×32;
- check the icon manually at 16×16 and 32×32;
- use transparency around the silhouette;
- do not put tiny text inside the icon.

Keep the 1024×1024 PNG master in the design source; Windows ICO itself normally tops out at 256×256.
