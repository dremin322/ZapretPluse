# Security

Do not publish secrets, proxy credentials, personal paths, or sensitive log data in public Issues.

If you find a security problem in Zapret+, report it privately to the repository owner before publishing technical details.
Use GitHub private vulnerability reporting when it is enabled for the repository.

Zapret+ downloads application/component updates only from repositories configured in the source code.
Release assets are not installed unless GitHub provides a SHA-256 digest and the downloaded file matches it.

Download Zapret+ only from this repository and its GitHub Releases.
